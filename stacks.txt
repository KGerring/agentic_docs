# StackMap

> A curated knowledge graph of 421 open-source AI & agent repos. Every connection is a typed, human-reviewed relationship (complements / alternative / built_with) with the "why" written down. Catalog version 2026.10.08 (updated daily; additive within a day).

## Start here (curated paths)
